## Критический путь и зависимости
Критическими (`[КП]`) являются задачи последовательной сборки ядра: **Документация (1.2–1.3) → Модули логики (1.5) → Поэтапная сборка `main.py` (1.6 → 2.1 → 2.2 → 2.3 → 2.4) → Тестирование (3.1–3.2) → Выпуск (3.4)**. Задержка на любом из этих этапов сдвигает дату релиза `v1.0`.
