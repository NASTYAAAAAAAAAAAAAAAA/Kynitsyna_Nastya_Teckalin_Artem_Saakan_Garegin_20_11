# Источники материалов и данных

## Текстуры (`assets/textures/`)
Условные учебные текстуры (`sun.png`, `mercury.png`, `venus.png`, `earth.png`, `mars.png`, `jupiter.png`, `saturn.png`, `uranus.png`, `neptune.png`) взяты из материалов учебного репозитория преподавателя (`lesson/assets/textures/`). Используются исключительно в учебных целях.

## Справочные астрономические данные (`src/planet_data.py`)
Значения экваториальных диаметров (км), средних расстояний от Солнца (млн км) и сидерических периодов обращения округлены для наглядного отображения в учебных карточках.
