# Техническое задание на разработку «MySpace»

## 1. Состав и назначение файлов
- `src/planet_data.py` — кортежи параметров 8 планет (`PLANETS`), список фактов (`FACTS`) и множество идентификаторов (`IDS`).
- `src/storage.py` — функции `load_notes()` и `save_notes()` для чтения и атомарного сохранения заметок в UTF-8.
- `src/motion.py` — чистые математические функции расчёта координат на орбите (`orbit_position`), шага угла (`next_angle`) и границ зума (`zoom_distance`).
- `src/main.py` — точка входа, инициализация окна Ursina, построение 3D-сцены, UI-панелей, обработка ввода и цикл обновления `update()`.
- `assets/textures/` — PNG-текстуры Солнца и восьми планет.
- `data/notes.txt` — файл пользовательских заметок (создаётся автоматически при первом сохранении, исключён из Git).
- `tests/test_logic.py` — модульные тесты логики и файлового хранилища (`unittest`).
- `tests/manual_checks.md` — чек-лист ручного тестирования интерфейса.

## 2. Компоновка интерфейса
```text
+-----------------------------------------------------------------------+
| MYSPACE                                                               |
| [Меркурий]                                      +-------------------+ |
| [Венера]                                        |   [Изображение]   | |
| [Земля]                                         | Название и факты  | |
| ...                                             |                   | |
| [Нептун]            < 3D-СЦЕНА СИСТЕМЫ >        | Моя заметка:      | |
|                                                 | [ Поле ввода    ] | |
| [Общий вид R]                                   | [   Сохранить   ] | |
| [Пауза] Скорость: x1 [0.5] [1] [5] [10]         +-------------------+ |
| Статус: ... / Размеры, расстояния и скорости условные                 |
+-----------------------------------------------------------------------+
```

## 3. Управление
- **ЛКМ** — выбор планеты в сцене или нажатие кнопки интерфейса.
- **Колесо мыши** — изменение дистанции камеры (заблокировано при наведении курсора на UI).
- **ПКМ + движение мыши** — поворот камеры вокруг текущей цели.
- **Пробел** — пауза / возобновление движения.
- **R** — возврат к общему виду.
- **Esc** — выход из программы.
- *Примечание:* при активном поле ввода заметки (`note_field.active == True`) нажатия `Пробел` и `R` вводятся как текст и не вызывают паузу или сброс камеры.

## 4. Формат хранения заметок (`data/notes.txt`)
- Кодировка: `UTF-8`.
- Формат строки: `<id_планеты>|<текст_заметки>` (например: `earth|Моя заметка`).
- Разделение строки при чтении выполняется строго по первому символу `|` (`split('|', 1)`), поэтому внутри текста заметки символ `|` допускается.
- Символы переноса строки (`\n`, `\r`) при сохранении заменяются пробелами.

## 5. Правила работы с файлом заметок
- При первом запуске файл `data/notes.txt` может отсутствовать — приложение запускается с пустым словарём заметок.
- При сохранении автоматически создаётся папка `data/`, данные записываются во временный файл `data/notes.tmp`, после чего выполняется атомарная замена `data/notes.txt`.

## 6. Ограничения
- Переключение на другую планету или закрытие окна без нажатия кнопки «Сохранить» приводит к потере несохранённого текста в поле ввода. Это ограничение зафиксировано в руководстве пользователя.
