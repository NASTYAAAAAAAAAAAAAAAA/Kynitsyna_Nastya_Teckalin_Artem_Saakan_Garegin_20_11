# MySpace — интерактивный симулятор Солнечной системы

**Автор:** Куницына Анастасия,Саакян Гарегин,Текалин Артем,11ТЭС 
**Заказчик:** учебный центр MySpace  
**Статус:** версия 1.0 (разработана и протестирована)

## Назначение
Настольное учебное приложение на Python и Ursina для визуального изучения Солнечной системы. Позволяет наблюдать движение восьми планет, управлять скоростью анимации, приближать и вращать камеру, просматривать справочные карточки планет и сохранять личные текстовые заметки по каждой планете.

> **Примечание:** Размеры планет, расстояния до Солнца, скорости движения и текстуры условные и подобраны для наглядности.

## Функциональность
- Отображение Солнца, восьми планет с текстурами, орбит, кольца Сатурна и звёздного фона.
- Управление скоростью времени: пауза (`Пробел`) и множители `×0.5`, `×1`, `×5`, `×10`.
- Выбор любой планеты кликом мыши по сфере или через панель кнопок слева.
- Свободное вращение (ПКМ), масштабирование (колесо мыши с защитой от попадания внутрь объекта) и возврат к общему виду (`R`).
- Информационная карточка выбранной планеты с изображением и основными характеристиками.
- Сохранение личных заметок (до 160 символов) в локальный файл `data/notes.txt` в кодировке UTF-8.

## Установка и запуск
1. Создайте и активируйте виртуальное окружение:
   - Windows PowerShell: `python -m venv .venv` и `.venv\Scripts\Activate.ps1`
   - macOS / Linux: `python3 -m venv .venv` и `source .venv/bin/activate`
2. Установите зависимости: `python -m pip install -r requirements.txt`
3. скопируйте содержимое архива в любую папку (рекомендация, в пути исключить кирилицу)
4. откройте папку в редакторе кода
5. Запустите приложение: `python src/main.py`

## Управление
- **ЛКМ по планете или кнопке слева** — выбрать планету и открыть карточку.
- **Колесо мыши** — приблизить / отдалить камеру.
- **ПКМ + перемещение мыши** — повернуть камеру вокруг текущей цели.
- **Пробел** — пауза / продолжить движение (не срабатывает при вводе заметки).
- **R** — вернуться к общему виду (не срабатывает при вводе заметки).
- **Esc** — выйти из приложения.
